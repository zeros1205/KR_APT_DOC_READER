# iOS App Store Connect 심사 제출 입력값 모음

App Store Connect 콘솔에서 "심사에 추가할 수 없음" 오류로 표시되는 항목을 한 번에 채울 수 있도록, 필요한 모든 텍스트와 설정값을 이 문서 한 곳에 모아 두었습니다. 콘솔 화면의 각 입력란에 그대로 복사·붙여넣기 하면 됩니다.

- **앱 이름(Display Name)**: 정과장의 청약노트
- **번들 ID**: `app.aptnote.mobile`
- **언어**: 한국어(기본)
- **연관 도메인**: `apt-note.com`

```

■ 주요 기능

청약노트는 공식 청약 창구가 아닙니다. 실제 청약 신청과 일정 확인은 반드시 한국부동산원 청약홈(applyhome.co.kr)에서 직접 진행해 주세요. 본 앱이 제공하는 모든 정리 내용은 의사결정 보조 정보이며, 분양가·일정의 최종 책임은 모집공고문 원본에 있습니다.
```

## 7. 앱 개인정보(App Privacy) — 데이터 수집 설문

ASC 콘솔 → 앱 개인정보(App Privacy) 섹션에서 아래 답변을 그대로 선택·입력하면 됩니다.

### 7.1 "이 앱에서 데이터를 수집합니까?"
- **예(Yes, we collect data from this app)** — 푸시 토큰을 수집하기 때문에 "예" 선택.

### 7.2 수집하는 데이터 항목

| 데이터 카테고리 | 데이터 유형 | 사용 목적 | 사용자와 연결됨? | 추적 용도? |
|---|---|---|---|---|
| 식별자(Identifiers) | **장치 ID(Device ID)** — APNs 푸시 토큰 | 앱 기능(App Functionality) — 신규 분양공고 알림 발송 | 아니요(Not linked to user) | 아니요(Not used for tracking) |

그 외 모든 카테고리는 **수집하지 않음(Not collected)** 으로 설정합니다. 구체적으로 다음 항목 모두 "수집 안 함":

- 연락처 정보(이름, 이메일, 전화번호, 주소, 기타 사용자 연락처 정보)

- 금융 정보
- 위치(정확한 위치, 대략적인 위치)
- 민감 정보
- 연락처
- 사용자 콘텐츠(이메일·메시지, 사진·동영상, 오디오, 게임플레이 콘텐츠, 고객 지원, 기타 사용자 콘텐츠)
- 브라우징 기록
- 검색 기록
- 식별자(사용자 ID)
- 구매 기록
- 사용 데이터(제품 상호작용, 광고 데이터, 기타 사용 데이터)
- 진단(충돌 데이터, 성능 데이터, 기타 진단 데이터)

## 8. 빌드 선택(Build Selection)

콘솔의 "빌드(Build)" 섹션에서 + 버튼을 눌러 TestFlight에 업로드된 가장 최근 빌드를 선택합니다.

### 빌드가 보이지 않을 때

1. GitHub Actions → **"Build Signed Mobile App for TestFlight"** 워크플로우가 성공으로 끝났는지 확인.
2. ASC → **TestFlight** 탭에서 해당 빌드가 "Processing(처리 중)" 상태가 끝나고 "Ready to Submit(제출 가능)" 또는 그에 준하는 상태인지 확인. 처리에는 5~30분 정도 걸립니다.
3. 빌드가 "Missing Compliance(수출 규정 누락)" 로 표시되면, 같은 화면에서 **"이 앱은 표준 암호화 외의 암호화를 사용하지 않습니다"** 에 해당하는 옵션을 선택해 제출.
4. 처리가 끝나면 콘솔의 앱 버전 페이지 → **빌드 + → 방금 처리 완료된 빌드 선택**.

### 다음 빌드 업로드가 필요한 경우

`docs/iOS_BUILD_HANDOVER.md` 의 "운영 체크리스트 → 매 빌드마다" 절차에 따라 `build_number` 를 한 단계 올려서 GitHub Actions 를 다시 실행하면 됩니다.
