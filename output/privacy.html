개인정보 보호정책

마지막 수정: 2026년 5월 18일

1. 개요

정과장의 청약노트(이하 "서비스")는 사용자의 개인정보를 매우 소중히 여기며, 「개인정보보호법」을 준수합니다. 본 정책은 서비스가 어떻게 개인정보를 수집, 이용, 보관 및 보호하는지 설명합니다.

2. 수집하는 정보

2.1 자동으로 수집되는 정보

서비스를 이용할 때, 다음 정보가 자동으로 수집될 수 있습니다:

  • Google Analytics: 페이지 방문 수, 방문 지속시간, 기기 유형, 브라우저 정보
  • 서버 로그: IP 주소, 접속 시간, 요청 URL, 리퍼러

2.2 사용자가 제공하는 정보

현재 서비스는 회원가입이 필요하지 않으며, 개인정보 입력 폼이 없습니다.

🔒 중요: 검색 입력창에 입력한 단지명은 로컬 브라우저(또는 모바일 앱 내부 저장소)에만 저장되며, 서버로 전송되지 않습니다.

2.3 모바일 앱(Android · iOS)에서 수집되는 정보

정과장의 청약노트 모바일 앱은 다음 항목만 수집·처리합니다. 이름·전화번호·이메일 등 직접 식별 가능한 개인정보는 수집하지 않습니다.

  • 푸시 알림용 디바이스 토큰: 신규 분양공고 알림을 보내기 위해 Firebase Cloud Messaging(FCM) 또는 Apple Push Notification service(APNs) 가 발급하는 디바이스 식별 토큰을 운영자 서버(Cloudflare Workers KV)에 저장합니다. 토큰만으로는 사용자 신원을 식별할 수 없으며, 사용자가 앱 알림을 비활성화하거나 앱을 삭제하면 다음 발송 시도에서 토큰이 자동으로 폐기됩니다.
  • 관심 지역 설정(선택): 사용자가 앱에서 직접 선택한 시/도·시/군/구 코드를 알림 매칭 용도로 토큰과 함께 저장합니다. 언제든 앱 화면에서 해제할 수 있습니다.
  • 로컬 저장 데이터: 즐겨찾기·검색 기록·테마 설정 등은 앱 기기 내 저장소에만 보관되며, 외부로 전송되지 않습니다.

iOS 앱은 광고 식별자(IDFA)를 수집하지 않으며, 앱 추적 투명성(App Tracking Transparency) 권한도 요청하지 않습니다. 위치정보, 연락처, 사진, 마이크, 카메라 등 시스템 권한도 요청하지 않습니다.

3. 정보 이용 목적

수집된 정보는 다음 목적으로만 이용됩니다:

  • 서비스 제공 및 개선
  • 사용자 경험 분석 (Google Analytics)
  • 시스템 안정성 및 보안 유지
  • 법률상 의무 이행

4. 정보 보관 및 삭제

  • Google Analytics 데이터: Google 정책에 따라 관리 (기본 26개월 보관)
  • 서버 로그: 90일 이후 자동 삭제
  • 검색 기록 · 즐겨찾기: 사용자 기기(브라우저 또는 모바일 앱)에서만 저장, 언제든 삭제 가능
  • 푸시 토큰 · 관심 지역 설정: 앱 알림 비활성화 또는 앱 삭제 시 다음 발송 시도에서 무효 토큰으로 폐기. 사용자가 contact@apt-note.com 으로 즉시 삭제를 요청할 수 있습니다.

5. 제3자 공유

정과장의 청약노트는 사용자의 개인정보를 제3자와 공유하지 않습니다.

단, 다음의 경우는 예외입니다:

  • 법원의 명령 또는 법률상 요구가 있을 때
  • 서비스 제공자(Google 등)와 필요한 범위 내에서 공유

6. 쿠키 및 유사 기술

서비스는 다음의 쿠키를 사용합니다:

  • Google Analytics: 사용자 식별 및 행동 분석

브라우저 설정에서 쿠키를 거부할 수 있으나, 서비스 이용에 제약이 생길 수 있습니다.

7. 보안

정과장의 청약노트는 사용자 정보 보호를 위해 업계 표준의 보안 조치를 취합니다:

  • HTTPS 암호화 통신
  • 접근 제어 및 데이터 암호화
  • 정기적인 보안 감시

8. 광고

본 서비스는 두 가지 광고 채널을 사용할 수 있습니다:

  • 웹사이트(apt-note.com): Google AdSense
  • 모바일 앱(Android): Google AdMob
  • 모바일 앱(iOS): 광고를 표시하지 않으며, 광고 식별자(IDFA)도 수집하지 않습니다.

Android 앱은 Android 광고 ID(Advertising ID)를 사용하여 광고 게재·측정·사기 방지·맞춤 광고에 활용합니다. 사용자는 단말의 설정 → Google → 광고 메뉴에서 광고 ID 를 재설정하거나 "맞춤 광고 사용 안함" 을 선택할 수 있습니다.

Google 의 광고 데이터 처리 방식은 Google 광고 정책 을 참고하세요.

9. 사용자의 권리

본 서비스는 회원가입을 받지 않으며, 사용자 식별 정보를 별도로 저장하지 않습니다. 그 결과 운영자가 직접 행사해드릴 수 있는 권리는 제한적이지만, 다음의 방법으로 본인의 데이터를 통제하실 수 있습니다:

  • 추적 거부: 브라우저 쿠키 차단 또는 Google Analytics 옵트아웃 도구 사용
  • 맞춤 광고 거부: 모바일 단말의 광고 ID 재설정 또는 "맞춤 광고 사용 안함" 선택
  • 로컬 데이터 삭제: 앱·브라우저의 설정 화면에서 검색 기록·즐겨찾기를 사용자가 직접 삭제
  • 서버 로그 삭제 요청: 별도 요청이 없으면 90일 이후 자동 삭제. 더 빠른 삭제·열람을 원하시면 아래 연락처로 요청하실 수 있습니다 (개인 식별 정보가 없어 본인 확인이 어려운 경우 응답이 제한될 수 있음).

10. 정책 변경
