검수·운영 정책

콘텐츠가 어떻게 만들어지고 검증되는지 단계별로 공개합니다

1. 우리의 약속

정과장의 청약노트는 분양 공고문의 핵심 정보를 빠르게 정리해 드리는 것을 목적으로 합니다. 자동화 도구의 도움을 받지만, 사실 정보는 청약홈 공공데이터를 단일 정본으로 삼고 발행 전 사람이 한 번 더 확인합니다. 이 페이지는 그 절차를 숨김없이 공개합니다.

2. 콘텐츠 제작 흐름

  1. 데이터 수집 (자동) 매일 한국부동산원 청약홈 공공데이터 OpenAPI에서 신규·갱신 분양 공고를 수집합니다. 분양가·모집공고일·당첨자 발표일·자격 요건·공급세대수 등 구조화된 필드는 항상 원본 API 값을 그대로 보존합니다.
  2. AI 보조 초안 작성 Claude·GPT·Gemini가 보조 도구로 사용됩니다. 다만 LLM은 문장화·요약·Q&A 작성에만 관여하고, 분양가·일정·자격 같은 사실 데이터를 생성하거나 추정하지 않습니다. 해석이 필요한 단지 규모·소형·대형 같은 표현은 정책상 금지되어 있어 본문에 등장하지 않습니다.
  3. 인간 검수 (발행 게이트) 정과장 팀이 발행 전 모집공고문 원본과 페이지를 1:1 대조해 통과한 페이지만 게재합니다. 검수 통과하지 못한 페이지는 발행되지 않습니다.
  4. 발행 후 갱신 모집공고문이 정정·변경되면 24시간 내 페이지에 반영합니다. 변경 이력은 페이지 하단의 "마지막 검토" 일자로 확인할 수 있습니다.

4. AI가 하는 일과 하지 않는 일

AI가 보조하는 영역

  • 공고문 본문에서 분양가·일정 등 구조화된 데이터를 추출하는 1차 파싱 보조
  • 단지 소개·자금 계획 요약·Q&A 초안 작성 (문장 다듬기)
  • 입지·교통·생활 인프라 요약 초안

AI가 하지 않는 일 (정책상 금지)

  • 분양가·일정·세대수·자격 같은 사실 데이터의 자체 생성·추정
  • 단지 규모(소형·중형·대형) 같은 해석성 표현
  • 특정 단지의 투자 가치·청약 권유 판단
  • 검증되지 않은 외부 출처 인용

5. 데이터·이미지 출처

  • 분양 공고: 청약홈(applyhome.co.kr) 공공데이터 OpenAPI
  • 지도·좌표: Kakao Local API
  • 건설사 저작물(조감도·평면도·위치도): 자동 삽입하지 않으며 PLACEHOLDER로 안내
  • 분위기 이미지: Unsplash·Pexels CC0 라이선스 (페이지에 출처 표기)

6. 광고 정책

청약노트는 운영 비용 충당을 위해 Google AdSense 기반 광고를 도입할 예정입니다. 광고 도입 시 다음 원칙을 지킵니다.

  • 광고와 본문 콘텐츠를 시각적으로 명확히 구분합니다.
  • 모집이 종료된 공고 페이지에서는 광고 노출을 제한합니다.
  • 특정 단지·시공사를 옹호하거나 비방하는 후원성 콘텐츠는 게재하지 않습니다.

7. 정정 요청·문의

페이지에서 오류, 오기, 누락을 발견하셨다면 알려 주세요. 정정 요청은 영업일 기준 24시간 이내에 검토·반영됩니다.

  • 이메일: contact@apt-note.com
  • 제목 예시: [정정요청] 단지명 - 항목
  • 처리 결과: 페이지 하단의 "마지막 검토" 일자 갱신
중요 안내. 청약노트는 청약 신청 창구가 아닙니다. 실제 청약 신청, 자격 판단, 최종 일정 확인은 반드시 청약홈에서 직접 확인해 주세요. 청약노트의 정리 내용은 의사결정 보조 정보이며, 모든 사실의 최종 근거는 모집공고문 원본에 있습니다.
