# 개인정보처리방침

**최종 수정일**: 2026년 4월 27일  
**시행일**: 2026년 5월 1일

---

## 1. 개인정보보호 정책

apt-note(이하 "앱")는 이용자의 개인정보를 매우 중요하게 여기며, 「개인정보보호법」, 「정보통신망이용촉진및정보보호등에관한법률」 등 관련 법령을 준수합니다.

본 개인정보처리방침은 앱이 제공하는 서비스(이하 "서비스")를 이용하는 과정에서 수집·이용하는 개인정보의 처리 방법에 대해 설명합니다.

---

## 2. 수집하는 개인정보

### 2.1 수집 항목

앱은 서비스 제공을 위해 최소한의 개인정보만 수집합니다.

#### 필수 수집 정보
| 항목 | 설명 | 수집 시점 |
|------|------|---------|
| **디바이스 ID** | 기기 고유 식별자 | 앱 설치 시 |
| **FCM 토큰** | Firebase Cloud Messaging 토큰 | 앱 실행 시 |
| **관심지역** | 사용자가 선택한 지역명 (최대 3개) | 온보딩/설정 변경 시 |
| **즐겨찾기 목록** | 저장한 분양공고 ID | 즐겨찾기 추가/제거 시 |
| **알림 설정** | 푸시 알림 활성화 여부, 조용한 시간 | 설정 변경 시 |
| **캐시 데이터** | 조회한 분양공고 정보 (24시간 TTL) | 포스트 조회 시 |

#### 자동 수집 정보
| 항목 | 설명 |
|------|------|
| **앱 버전** | 사용 중인 앱 버전 |
| **OS 타입** | Android 또는 iOS |
| **API 접근 로그** | 앱이 API에 접근한 시간, IP 주소 |

### 2.2 수집하지 않는 정보 (명시적 제외)

앱은 다음의 민감 정보를 **절대 수집하지 않습니다**:

- ❌ 이름, 전화번호, 이메일 주소
- ❌ 금융 정보 (계좌, 신용카드, 소득)
- ❌ 신원 정보 (주민등록번호, 여권번호)
- ❌ 위치 정보 (GPS, 위도/경도)
- ❌ 생체 정보 (지문, 홍채)
- ❌ 의료 정보, 건강 정보
- ❌ 카메라, 마이크, 연락처 접근
- ❌ 브라우징 히스토리, 검색어 기록

## 3. 개인정보 수집 목적

### 3.1 필수 목적 (동의 필수)

| 데이터 | 수집 목적 | 법적 근거 |
|--------|---------|---------|
| **FCM 토큰** | 분양공고 알림 푸시 메시지 발송 | 사용자 동의 |

- 서비스 개선 및 오류 수정

- 서비스 통계 및 분석

## 6. 개인정보 제3자 공유

### 6.1 공유하는 경우

앱은 사용자의 동의 없이 개인정보를 제3자와 공유하지 않습니다. **단, 다음의 경우 예외:**

| 상황 | 공유 대상 | 공유 정보 | 법적 근거 |
|------|---------|---------|---------|
| **FCM 푸시 알림** | Google Firebase | FCM 토큰, 기기 ID | 알림 서비스 제공 |
| **통계 분석** | Google Analytics (선택) | 앱 사용 통계 (익명) | 서비스 개선 |
| **법적 요청** | 수사기관 | 필요 최소 정보 | 법원 명령 |

### 6.2 공유하지 않는 경우

- 광고 회사 (AdSense는 공개 데이터만 사용)
- 마케팅 업체
- 제3자 SDK (수집 최소화)
- 소셜 미디어

## 7. 사용자 권리

### 7.1 개인정보 조회 & 수정

사용자는 언제든 자신의 개인정보를 확인하고 수정할 수 있습니다.

**방법:**
1. 앱 → 설정 → 개인정보
2. 또는 privacy@apt-note.com으로 이메일

**응답 기간**: 요청 후 5 업무일 이내

### 7.2 개인정보 삭제 (잊혀질 권리)

사용자는 언제든 자신의 개인정보 삭제를 요청할 수 있습니다.

**삭제 방법:**
1. 앱 → 설정 → "모든 데이터 삭제" 버튼
2. 또는 privacy@apt-note.com으로 요청

**삭제 대상:**
- ✅ 로컬 저장 데이터 (즐겨찾기, 설정)
- ✅ Firebase 토큰 및 기기 정보
- ✅ 캐시 데이터

**삭제 제외:**
- ❌ 법적 의무 (회계법, 통신비밀보호법)
- ❌ 분쟁 해결 (고소 등)

### 7.3 알림 거부

사용자는 푸시 알림을 언제든 거부할 수 있습니다.

**방법:**
1. 앱 → 설정 → 알림 설정 → OFF
2. 또는 Android/iOS 설정 → 앱 권한 → 알림 비활성화

**참고**: 알림을 거부해도 앱 사용은 가능합니다.

### 7.4 동의 철회

사용자는 개인정보 수집 동의를 언제든 철회할 수 있습니다.

**절차:**
1. 앱 → 설정 → 동의 관리
2. "푸시 알림 동의" 체크 해제
3. 저장

## 11. 개인정보 처리 절차

### 11.1 수집 → 이용 → 삭제 흐름

```
1. 수집 (앱 설치 시)
   ├─ 온보딩에서 권한 설명
   └─ 명시적 동의 획득

2. 이용 (앱 사용 중)
   ├─ 로컬 저장소에만 보관
   └─ 서버 송신 최소화

3. 보관 (지속)
   ├─ FCM 토큰: Firebase 관리
   └─ 기타 데이터: 로컬 저장

4. 삭제 (앱 삭제 시)
   ├─ 자동 삭제: 로컬 모든 데이터
   ├─ Firebase 처리: 토큰 유효기간 만료
   └─ 사용자 요청 삭제: 즉시
```

### 11.2 데이터 처리 기록

앱은 다음을 기록합니다:
- API 호출 로그 (접근 시간, IP)
- 권한 요청 기록
- 동의/철회 기록

**보관 기간**: 1년 (법적 의무)

## 16. 기타 사항

### 16.1 쿠키 및 추적

앱은 쿠키를 사용하지 않습니다 (모바일 앱이므로).
- 웹 버전 (향후): 쿠키 미사용 (또는 사전 동의)

### 16.2 광고

앱에 Google AdSense 광고가 표시될 수 있습니다:
- Google은 공개 데이터 기반 광고 (개인정보 미사용)
- 광고 타겟팅 거부: Google 설정 (myaccount.google.com)

### 16.3 링크

앱은 청약홈(applyhome.co.kr) 등 외부 링크를 포함할 수 있습니다:
- 외부 사이트 이용 시 해당 개인정보처리방침 적용
- apt-note는 책임 없음

### 16.4 자동화된 의사결정

앱은 다음을 사용하지 않습니다:
- AI 기반 자동 의사결정
- 프로파일링
- 자동 거부/승인

## 부록: FAQ

### Q1. 내 위치가 추적되나요?
**A:** 아니요. 위치 권한을 요청하지 않으며, GPS 접근이 없습니다.

### Q2. 데이터가 광고주에게 팔리나요?
**A:** 절대 아니요. 개인정보를 판매하지 않습니다. Google AdSense만 사용하며, 공개 데이터 기반입니다.

### Q3. 내 이름이 저장되나요?
**A:** 아니요. 이름, 이메일, 전화번호를 수집하지 않습니다.

### Q4. 앱을 삭제하면 데이터가 완전히 삭제되나요?
**A:** 네. 로컬 데이터는 앱 삭제 시 자동 삭제되고, Firebase 토큰은 유효기간 만료 시 자동 삭제됩니다.

### Q5. 중국에 데이터가 저장되나요?
**A:** 아니요. 중국 서버를 사용하지 않으며, 모든 데이터는 한국 또는 Google 글로벌 서버에만 저장됩니다.

### Q6. 정책이 변경되면 알려줄 건가요?
**A:** 네. 중요한 변경 시 앱 팝업으로 알리며, 재동의를 요청합니다.
