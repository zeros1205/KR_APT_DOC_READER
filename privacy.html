개인정보처리방침

⚠️ 중요
본 개인정보처리방침은 "apt-note" 앱(Google Play)의 개인정보 처리에 관한 방침입니다.
정책 변경 시 앱 내 공지를 통해 알려드립니다. (최근 3년 버전 보관)

1. 개인정보보호 정책

apt-note(이하 "앱")는 이용자의 개인정보를 매우 중요하게 여기며, 「개인정보보호법」, 「정보통신망이용촉진및정보보호등에관한법률」 등 관련 법령을 준수합니다.

본 개인정보처리방침은 앱이 제공하는 서비스를 이용하는 과정에서 수집·이용하는 개인정보의 처리 방법에 대해 설명합니다.

2. 수집하는 개인정보

2.1 필수 수집 정보

항목 설명 수집 시점
디바이스 ID 기기 고유 식별자 앱 설치 시
FCM 토큰 Firebase Cloud Messaging 토큰 앱 실행 시
관심지역 사용자가 선택한 지역명 (최대 3개) 온보딩/설정 변경 시
즐겨찾기 목록 저장한 분양공고 ID 즐겨찾기 추가/제거 시
알림 설정 푸시 알림 활성화 여부, 조용한 시간 설정 변경 시
캐시 데이터 조회한 분양공고 정보 (24시간 TTL) 포스트 조회 시

2.2 수집하지 않는 정보 (명시적 제외)

앱은 다음의 민감 정보를 절대 수집하지 않습니다:

  • ❌ 이름, 전화번호, 이메일 주소
  • ❌ 금융 정보 (계좌, 신용카드, 소득)
  • ❌ 신원 정보 (주민등록번호, 여권번호)
  • ❌ 위치 정보 (GPS, 위도/경도)
  • ❌ 생체 정보 (지문, 홍채)
  • ❌ 의료 정보, 건강 정보
  • ❌ 카메라, 마이크, 연락처 접근
  • ❌ 브라우징 히스토리, 검색어 기록

데이터 수집 목적 법적 근거

4. 개인정보 보관 기간

4.1 로컬 저장 (기기에만 보관)

데이터 보관 기간 삭제 방법
즐겨찾기 앱 삭제 시까지 자동 삭제
알림 설정 앱 삭제 시까지 자동 삭제
캐시 24시간 자동 만료 + 설정에서 수동 삭제
디바이스 ID 앱 삭제 시까지 자동 삭제

4.2 사용자 요청 삭제

사용자가 원할 때 언제든 데이터를 삭제할 수 있습니다:

  • 앱 → 설정 → "모든 데이터 삭제" 버튼
  • 또는 지원 이메일로 요청: privacy@apt-note.com

삭제 응답 기간: 요청 후 5 업무일 이내

5. 개인정보 보안

5.1 기술적 보안 조치

  • 로컬 저장소: Capacitor Storage + SQLite 암호화 (AES-256)
  • 네트워크 통신: HTTPS (TLS 1.2 이상)
  • Firebase: Google에서 암호화 관리, OAuth 2.0 기반 인증

5.2 관리적 보안 조치

  • 개발팀 내 접근 제한
  • 로그 기록 및 모니터링
  • 정기적인 보안 업데이트
  • 취약점 스캔 (GitHub Actions)

6. 개인정보 제3자 공유

6.1 공유하는 경우

앱은 사용자의 동의 없이 개인정보를 제3자와 공유하지 않습니다. 단, 다음의 경우 예외:

상황 공유 대상 공유 정보
FCM 푸시 알림 Google Firebase FCM 토큰, 기기 ID
통계 분석 Google Analytics (선택) 앱 사용 통계 (익명)
법적 요청 수사기관 필요 최소 정보

6.2 공유하지 않는 경우

  • 광고 회사
  • 마케팅 업체
  • 제3자 SDK
  • 소셜 미디어

7. 사용자 권리

7.1 개인정보 조회 & 수정

사용자는 언제든 자신의 개인정보를 확인하고 수정할 수 있습니다.

방법:

  1. 앱 → 설정 → 개인정보
  2. 또는 privacy@apt-note.com으로 이메일

7.2 개인정보 삭제 (잊혀질 권리)

사용자는 언제든 자신의 개인정보 삭제를 요청할 수 있습니다.

  • 앱 → 설정 → "모든 데이터 삭제" 버튼
  • 또는 privacy@apt-note.com으로 요청

7.3 알림 거부

사용자는 푸시 알림을 언제든 거부할 수 있습니다.

  • 앱 → 설정 → 알림 설정 → OFF
  • 또는 Android/iOS 설정 → 앱 권한 → 알림 비활성화

참고: 알림을 거부해도 앱 사용은 가능합니다.

응답 기간: 요청 후 5 업무일 이내

9. 아동 정보 보호

앱은 14세 미만 아동의 개인정보를 수집하지 않습니다. 만약 14세 미만이 가입한 것으로 발견되면 즉시 계정을 삭제합니다.

10. 개인정보 처리 방침 변경

개인정보처리방침 변경 시:

  • 중요 변경: 앱 내 팝업 알림 + 재동의 요청
  • 경미한 변경: 웹사이트 공지
  • 변경 보관: 최근 3년치 아카이빙

공지일로부터 7일 후 자동 적용되며, 이전 버전 요청 시 제공됩니다.

11. 보안 침해 시 대응

사용자의 개인정보가 침해되면 즉시 다음 조치를 취합니다:

  1. 원인 파악 및 조치
  2. 영향받은 사용자에게 즉시 알림 (앱 팝업 + 이메일)
  3. 수사기관 보고
  4. 개인정보보호위원회 신고

침해로 인한 피해는 민법상 손해배상을 청구할 수 있습니다.

12. 준거법 및 분쟁 해결

12.1 준거법

본 개인정보처리방침은 다음 법령을 준거법으로 합니다:

  • 개인정보보호법 (한국)
  • 정보통신망 이용촉진 및 정보보호 등에 관한 법률 (한국)
  • GDPR (EU 사용자)

12.2 분쟁 해결

  1. 협의 (privacy@apt-note.com)
  2. 개인정보보호위원회 민원 (www.privacy.go.kr)
  3. 소비자분쟁조정위원회 (www.ccn.go.kr)
  4. 법원 소송 (관할: 서울중앙지방법원)

FAQ

Q. 내 위치가 추적되나요?

A. 아니요. 위치 권한을 요청하지 않으며, GPS 접근이 없습니다.

Q. 데이터가 광고주에게 팔리나요?

A. 절대 아니요. 개인정보를 판매하지 않습니다. Google AdSense만 사용하며, 공개 데이터 기반입니다.

Q. 내 이름이 저장되나요?

A. 아니요. 이름, 이메일, 전화번호를 수집하지 않습니다.

Q. 앱을 삭제하면 데이터가 완전히 삭제되나요?

A. 네. 로컬 데이터는 앱 삭제 시 자동 삭제되고, Firebase 토큰은 유효기간 만료 시 자동 삭제됩니다.

Q. 정책이 변경되면 알려줄 건가요?

A. 네. 중요한 변경 시 앱 팝업으로 알리며, 재동의를 요청합니다.

Q. 문의하려면?

A. privacy@apt-note.com (개인정보) / support@apt-note.com (기술)
